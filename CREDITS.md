## Ghidra-Rare changes

All in this repository's `ghidra-rare` branch, by the Ghidra-Rare project (see `GHIDRA-RARE.md` for the
verification that motivated each one):

- **MMI and VU0 macro-mode semantics.** Upstream implements the multimedia (MMI) and VU0 macro-mode
  instructions as pcodeop stubs (`_paddb(...)`, `_vadd(...)`). They are now real p-code, generated by
  `tools/gen_ee.py` into `data/languages/eecore.sinc` and `data/languages/vu.sinc`, using lane registers
  (`lanes.sinc`, `lanefields.sinc`) for the 128-bit GPRs, HI/LO, the vf registers and ACC. `macros.sinc`,
  `cop2.sinc` and `vuupper.sinc` are replaced by the generated files.
- **VU macro mode details**: vf register lanes are x, y, z, w from the lowest bits (upstream had w, y, z, x);
  vf0 reads (0, 0, 0, 1.0) and vi0 reads 0, and writes to them are discarded; dest masks are applied per lane;
  vi16-vi31 are the control registers (Status, MAC, clipping, R, I, Q, ... as `cfc2`/`ctc2` operands, upstream
  #76); VU0 data memory accesses (`vlqi`, `vsqd`, `vilwr`, `viswr`, ...) address the EE's view of VU0 memory at
  0x11004000; `vclipw` computes the clipping flags; `vdiv`/`vsqrt`/`vrsqrt` write Q; `vrinit`/`vrget`/`vrxor`
  use R (beardypig#72); `vilwr`/`viswr` take exactly one dest field (VIWR table); `vadda`/`vmsuba` operand
  order as both reference disassemblers print it; `vcallms` shows the byte address; generic `c2` for other
  COP2 operations; integer register fields accept vi0-vi31 as GNU objdump does.
- **Base MIPS fixes**: `divu` divided signed; `tge` compared unsigned; 64-bit variable
  shifts used the whole rs value instead of its low 6 bits; `div`/`divu`/`jr`/`jalr`/`dsllv`... accepted
  non-zero reserved fields; `jalr rd, rs` with rd = rs read the link value as the target; `bgezal`/`bltzal`
  with rs = ra tested the new ra; `jr ra` was shadowed by `jr rs` (now a return); `add`/`addi`/`sub`/`dadd`/
  `daddi`/`dsub` raise the integer-overflow exception (`integerOverflow` pcodeop) instead of wrapping silently;
  `lq`/`sq`/`lqc2`/`sqc2` ignore the low four address bits; reads of `$zero` in any width (including the
  128-bit MMI and the load/store base) are the constant 0; invented aliases `clear`, `moveq` removed (beardypig
  #38); the `dsra32` special case removed (beardypig #58); GNU-style aliases added (`beqz`, `bnez`, `beqzl`,
  `bnezl`, `bal`, `neg`, `negu`, `dneg`, `dnegu`, `move` for `addu`); trap instructions show their code field;
  `sync` / `sync.p` decoded by stype; `mtsab`/`mtsah` show the signed immediate and `mtsah` uses 3 bits.
- **COP0**: `bc0t` lacked its operand and `bc0tl` was named `bc0fl`; `ei`/`di` set and clear Status.EIE (in
  kernel mode or with Status.EDI); `eret` returns through ErrorEPC or EPC and clears ERL / EXL; `tlbr` read
  PageMask with the EntryLo1 operation; `mfc0` of Count and Random goes through `readCount`/`readRandom`
  pcodeops so the decompiler no longer folds polling loops (upstream #98); `mfpc`/`mtpc`/`mfps`/`mtps` take the
  register number as GNU objdump does; the catch-all `cop0` became the objdump-style `c0` (CO bit set only).
- **COP1**: register order f0..f31 (upstream interleaved f1 f0 f3 f2 ...); lower-case `.s` mnemonics;
  `cvt.w.s` saturates out-of-range values; `max.s`/`min.s` select by comparison; `c.cond.s` and `abs.s`
  require their reserved fields to be zero; invented `clear` aliases removed; catch-all `c1`.
- **ELF opinion**: also recognises R5900 ELFs by EF_MIPS_MACH = 0x92 regardless of the ABI bits, so the n32
  executables of the current ps2dev toolchain (e_flags 0x20920025) import as `r5900:LE:32:default` instead of
  generic MIPS (upstream #127).
- **Flags**: COP1 FMAC operations set FCR31 O / U, DIV.S / SQRT.S / RSQRT.S set I / D (with the sticky bits;
  SQRT.S / RSQRT.S use |ft|); VU0 FMAC operations write the MAC flags (vi17) and Status (vi16), VDIV / VSQRT /
  VRSQRT set Status I / D.
- **Hardware registers** (upstream #93): the 173 EE register names moved from SLEIGH symbols in the ram space
  (`mmio.sinc`, removed) to `<default_symbols>` labels in `r5900.pspec`, so references to them are created;
  `ghidra_scripts/ImportMMIORegisterLabels.java` updated.
- `EE_ElfExtension.canHandle(ElfHeader)` claims only R5900 / IRX / ERX ELFs and MIPS I / III ELFs without a
  machine variant; it used to claim every MIPS ELF, breaking e.g. PSP images (kotcrab/ghidra-allegrex #49).
- `MipsR5900AddressAnalyzer`: `&` → `&&` in a boolean test (beardypig #37).
- `build.gradle` replaced by Ghidra-Rare's standard one; `.gitignore` additions; README updated (limitations,
  install, Ghidra-Rare notes).
- Added `GHIDRA-RARE.md`, this file, `tools/gen_ee.py` and the test suite in `test/`.

## Sources used for Ghidra-Rare's changes

- Reference disassemblers, run as black boxes: GNU objdump 2.45 (`-m mips:5900`) and the ps2dev toolchain's
  binutils; rabbitizer 1.16.2 (MIT, Decompollaborate), whose MIT-licensed R5900 opcode tables were also read.
- [wasaylor/r5900-opcodes](https://github.com/wasaylor/r5900-opcodes) (MIT, William Saylor), commit
  `d734aeac9b6cfbfb36d36b050e93a2f88d996afc`: opcode tables transcribed from the EE Core Instruction Set Manual,
  used as a third encoding reference by `test/table_check.py`.
- [ps2tek](https://psi-rockin.github.io/ps2tek/) for the COP0 Status bits (EIE, EDI, EXL, ERL, KSU) and ERET.
- No GPL source code (binutils opcode tables, PCSX2, MAME) was read.
